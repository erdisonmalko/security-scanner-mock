🔑 How to Enable Full Functionality

This demo uses a local FastAPI backend. The browser sends data to your local scanner service for analysis.

⚠️ You must run the backend server:
uvicorn api.main:app --reload

  • Link Checker: Get free Google Safe Browsing API key
  • File Scanner: Get free VirusTotal API key (4 requests/minute)
  • Text Analyzer: Uses local pattern detection (no API needed)

See scanner.js for API integration instructions.
